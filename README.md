# 📊 HR Employee Attrition Analytics

An interactive HR analytics dashboard evaluating workforce retention patterns across departments, job satisfaction levels, and overtime status. Built using Python, SQL Server via SQLAlchemy, and Streamlit.

🔗 **Live Demo:** [HR Attrition Analytics App](https://hassan-farahat-hr-attrition-analytics-app-7lvspp.streamlit.app)

## 🛠️ Tech Stack & Architecture
- **Language:** Python
- **Database:** SQL Server (SQLAlchemy + PyODBC)
- **Frontend Dashboard:** Streamlit
- **Visualization:** Seaborn, Matplotlib

## 📌 Features
- Data ingestion pipeline storing cleaned & feature-engineered records directly into SQL Server.
- Dynamic filtering by Department and Overtime Status.
- Key Metrics: Total Employees, Total Attrition, Attrition Rate (%), and Average Monthly Income.
- High-level visualizations analyzing retention by Department and Job Satisfaction.
- Embedded SQL data viewer for direct dataset inspection.
